# Vitalworks Limited — Corporate Website

Professional, accessible, search-optimized company website for Vitalworks Limited.

## Development

```bash
npm install
npm run dev
npm run build
npm run lint
```

Next.js App Router, TypeScript and lightweight CSS. Corporate claims, product publication, contact details and approved logos must be validated before production release.

See `docs/WEBSITE_REQUIREMENTS.md` and `docs/SEO_IMPLEMENTATION.md`.
