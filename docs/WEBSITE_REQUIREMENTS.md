# Vitalworks Limited — Corporate website implementation requirements

**Primary specification:** Corporate Website Design, Content, Architecture and Implementation Requirements v1.0 (prepared 13 October 2026). The complete original document is maintained as a separate deliverable and must be placed in this docs directory when available to development teams.

## Corporate scope
Registered entity: VITALWORKS LIMITED, Uganda. The Memorandum and Articles of Association permit software and SaaS, AI/data science, enterprise systems integration, infrastructure/cloud/DevOps, cybersecurity, managed services, advisory, training, R&D, data insights, sector solutions, IoT, fintech enablement, and partnerships. Registered objectives are not evidence of current services, clients, product availability or certifications.

## Visual brief
Elegant and restrained, spacious editorial layouts, calm navy/slate neutrals with **final palette determined by the selected official logo**, purposeful imagery, no decorative AI imagery, no fabricated testimonials, no repetitive card walls, visible focus states, functional mobile navigation, sensible motion and reduced-motion support.

## Navigation
Company · Solutions · Products · Industries · Insights · Contact. Content pages should be readable and internally linked, with an obvious contact pathway and mobile-accessible menus.

## Implementation acceptance
- Approved official logo and brand colors replace temporary text-mark.
- Responsive at small phone, tablet, laptop and widescreen viewports.
- Semantic accessible navigation and keyboard usability, WCAG 2.2 AA target.
- Every public page gets specific title, description and canonical path; XML sitemap and robots available.
- Actual deployment verified with Lighthouse SEO >=95, accessibility >=95, best practices >=95, performance >=90 target.
- Authentic copy, final contact details, verified portfolio and approved imagery.
- Operational contact channels, privacy disclosures and editorial workflow.

## Current first iteration
Next.js App Router foundation, homepage, company, solutions including service-specific pages, product portfolio, industries, insights, contact, reusable layout, responsive CSS and SEO foundation. It is a first implementation phase, **not** complete certification or an approved production site.
