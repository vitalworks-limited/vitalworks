# Vitalworks Corporate Website — Visual Redesign v4

## Brand direction
Use original Vitalworks assets without redrawing the logo. Core colors: deep navy `#0B2032`, corporate orange `#F58220`, ivory highlights, and blue-grey secondary surfaces.

## Typography
All textual UI and headings now use Arial / Helvetica fallback, with stronger weight, readable body copy around 17px, 15px navigation, and responsive 40–89px heading scales. Preserve heading hierarchy and visible focus indicators.

## Section themes
- Header: pale blue-grey, stronger logo and navigation.
- Homepage hero: layered navy gradient, subtle geometric pattern, bright orange highlights and contrasting white text.
- Perspective/services: light blue-grey and cool-toned gradients with clear dividers.
- Architecture: deep navy graphical panel.
- Industries: warm ivory to blue-grey gradient.
- Portfolio: warm orange-blue gradient, offset navy mark panel.
- Call-to-action: corporate orange-to-peach background.
- Footer: deep navy architectural gradient.
- Interior pages: blue-grey base, dark navy emphasis sections and prominent form surface.

## Layout and accessibility
Keep broad editorial sections instead of excessive cards. Preserve responsive layouts, minimum touch target sizing, focus visibility and reduced-motion preference. Mobile uses 16px base copy and sufficiently large menu text.

Changes were committed to `src/app/globals.css` on `main`. Real mobile/desktop visual QA, typography contrast review, Vercel build checks and Lighthouse measurements remain outstanding.
