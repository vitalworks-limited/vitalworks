# Vitalworks Website — SEO implementation and certification

## Objective
Achieve a measurable technical SEO implementation with high Google Lighthouse and PageSpeed quality scores, without promising guaranteed rankings or a permanent 100/100 score. Scores depend on environment, page content and measurement conditions.

## Already implemented
- Next.js App Router with server-rendered and statically generated public pages.
- Dedicated metadata, titles, descriptions, canonical URLs and Open Graph descriptions for each public route.
- English document language, structured headings, semantic HTML, labeled navigation, skip link and responsive layout.
- Organization JSON-LD without unverified telephone, address, social media or logo.
- Dynamic sitemap at /sitemap.xml and robots.txt, including all published service detail routes.
- No automatically fabricated reviews, awards, ratings, case studies or customer statistics.
- Reduced-motion support and focus-visible outlines.

## Mandatory before deployment
1. Replace the placeholder NEXT_PUBLIC_SITE_URL with the validated production HTTPS hostname. Canonical URLs, structured data and sitemap must match the final domain.
2. Use an authorized company-owned visual identity, with properly optimized image assets and accurate alternative text.
3. Review every product and service statement against company-approved copy and factual evidence; remove unpublished or non-public initiatives as necessary.
4. Verify site ownership in Google Search Console and Bing Webmaster Tools, submit sitemap, and monitor indexing, coverage and search appearance.
5. Create unique OG images, social previews, favicon and app icons from official artwork.
6. Run Lighthouse and PageSpeed tests on live production URLs, desktop and mobile; record scores rather than assume them.
7. Meet Core Web Vitals at p75: LCP <= 2.5 seconds, INP <= 200 ms, CLS <= 0.1; track field data.
8. Aim for Lighthouse SEO >= 95, accessibility >= 95, best practices >= 95, and performance >= 90 on representative pages; investigate score regressions.
9. Add genuine long-form service copy, FAQs only when useful, sector-specific evidence, internal linking and meaningful image descriptions.
10. Verify 404 and redirect handling, robots rules, security headers, TLS, crawlability, metadata uniqueness, canonical consistency and structured data with search-engine validation tools.
11. Define and implement consent-aware analytics and privacy controls before tracking visitors.
12. Test contact workflows end-to-end before advertising them as operational.

## Do not claim
- Guaranteed first-page results, ranking positions, instant indexing or permanent 100% SEO.
- 100/100 Lighthouse before running a production audit.
- Any certification or validated product availability without evidence.
